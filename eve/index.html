Sobre esta ferramenta

não-comercial client-side projeto de fã

Ferramenta de mercado e arbitragem cross-region para EVE Online. Ela usa a API pública (ESI) e o SDE estático oficial. Não cobra nada, não tem paywall e não restringe acesso — conforme a política do desenvolvedor (Fenris Creations, ex-CCP Games) para Aplicações de terceiros.

Como os dados fluem

  • O seu navegador fala direto com esi.evetech.net e images.evetech.net.
  • Não existe servidor nosso, banco central, telemetria ou analytics.
  • Os dados coletados ficam no seu IndexedDB; os ajustes, no seu localStorage.
  • Nenhuma chamada autenticada, nenhuma chave de API, nenhum SSO/login.

Fontes de dados e endpoints

  • ESI — API pública, sem autenticação · esi.evetech.net/latest
    • GET /markets/{region_id}/orders/?order_type=all&datasource=tranquility&page={n} — ordens de mercado por região (paginação por X-Pages; cache por ETag/Expires)
    • GET /markets/{region_id}/history/?type_id={id}&datasource=tranquility — histórico diário de preço (modal de detalhe)
    • POST /universe/names/ — resolve IDs→nomes (apenas no build do SDE)
    • — limites lidos dos headers X-Ratelimit-*; backoff em 429 / Retry-After
    • — identifica a aplicação via X-User-Agent (browsers descartam User-Agent): EVE-Market/1.0 (+https://github.com/AjaxFB/AjaxFB.github.io)
  • Imagens — images.evetech.net — ícones de tipos exibidos direto do servidor oficial
  • SDE (dados estáticos oficiais) — developers.eveonline.com/static-data — build baixado uma vez por build/gen_sde.py e embutido em sde.js
  • Dotlan (link externo, só navegação) — evemaps.dotlan.net
